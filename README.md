# Lincoln Family

Encrypted family library with calendar and violin-practice pages. Open the GitHub Pages website and enter the shared family passphrase. Only encrypted family content is stored in this repository.

The violin page includes a daily assignment flow. A parent can select existing focus tasks or add a YouTube link, timestamps, and repetition count. Lincoln’s **Today’s Practice** view has Start/Pause controls, per-task completion, three practice modes, and a daily summary with total active practice time and recording upload actions. Assignment and session logs are encrypted in this browser with the family passcode. They stay on this browser and do not sync to other devices. Recordings are held temporarily in the page and can be reviewed or downloaded; download a take before reloading or locking the page to keep it.

Each recorded take has an **Upload as Private** action, an editable YouTube description prefilled with the reference link, assigned timestamps, repetition count, focus, and practice mode, and an optional playlist selector. Load playlists from the signed-in channel, choose one, and upload; the app uploads the video as **Private** and then adds it to that playlist. To enable uploads and playlist management, create a Google Cloud OAuth 2.0 Web client, enable the YouTube Data API v3, add this site's origin as an authorized JavaScript origin, and paste the client ID into `youtube-config.js`. For local Chrome, authorize `http://127.0.0.1:8000`; add the production GitHub Pages origin as well. The client ID is public; do not add a client secret. Upload and playlist operations use Google sign-in with the `youtube` permission. The access token is kept in memory only and cleared when the family page locks. Use HTTPS for the hosted site and camera access.
